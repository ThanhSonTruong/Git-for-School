\subsubsection{Complex equation}

The time–independent Schr{\"o}dinger equation is given by
\begin{equation}
  -\frac{\hbar^2}{2m} \nabla^2 \psi(\mathbf{r}) + V(\mathbf{r}) \, \psi(\mathbf{r}) 
= E \, \psi(\mathbf{r}),
\label{eq:schrodinger}
\end{equation}
where $\nabla^2$ is the Laplacian operator, $\psi(\mathbf{r})$ is the wave function and $V(\mathbf{r})$ gives the potential energy.
\subsection{Figures}

Figures are included to a latex docuemnt using syntax as seen below.

\begin{verbatim}
\begin{figure}[h]
    \centering
    \includegraphics[width=0.6\textwidth]{example.png}
    \caption{An example figure. Replace the file name and caption with your own.}
    \label{fig:example}
\end{figure}
\end{verbatim}

Comments:
\begin{itemize}
    \item The key line is the \texttt{\textbackslash includegraphics} command, which inserts the figure and allows you to specify its size.
    \item The image file must exist in the same folder as your \texttt{.tex} file. The recommended formats are \texttt{.png} or \texttt{.pdf}.
    \item To refer to the figure from the text, use its label, e.g.\ \texttt{see Figure\textasciitilde\textbackslash ref\{fig:example\}}.
\end{itemize}
